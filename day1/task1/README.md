과제1 
: 플로팅(Floating)상태에 대해 설명하고, 플로팅 상태가 문제가 되는 이유와 이를 해결하기위한 방법을 설명하시오. 

플로팅 상태란 입력 핀이 VCC나 GND 어느곳에도 연결되지 않아 핀의 전압이 0과 1 사이에서 불안정하게 떠있는 상태를 말한다.
플로팅 현상이 생기는 이유는 칩에서 전류가 0V인지 5V인지 2V인지 인식할 수 없기 때문에 발생한다.

플로팅 현상을 해결하기 위해선 풀업 저항과 풀다운 저항을 사용하면 된다.

풀업 저항 방법은 저항을 앞에 붙여줘서 플로팅 형상을 방법이다.
풀업 저항에서는 스위치가 열린 상태일 때 입력핀으로 전류가 흐르게 되고 전원전압과 같은 5V전압이 걸리게 된다. 그래서 입력 핀에는 1값이 읽히게 된다.
