과제1 : ADC 공부 내용 보고서로 작성

ADC는 전압을 0~1023 사이의 숫자로 바꿔주는 역할을 한다.

##ADMUX
ADMUX : 어떤 핀을, 뭘 기준으로 잴지 정한다.
ex) ADMUX = 0x40; (0b01000000)
  ->REFS1, REFS0 = 0, 1 -> 기준전압 AVCC 사용한다
  ->MUX4:0 = 00000 -> ADC0핀(PF0)을 측정
  : PF0핀에 들어오는 전압 0 ~ 5V를 0 ~ 1023으로 바꿔서 읽겠다는 뜻이다

##ADCSRA
ADCSRA는 ADC를 켜고, 분주비를 정하고 시작한다는 뜻이다.
 ex) ADCSRA = 0x87; (0b100000111)
   ->ADEN = 1 -> ADC 켜기
   ->ADPS2: 0 = 111 -> 분주비 128 (현재 우리가 사용하는 atmega128은 분주비 128이 고정4
ADCSRA의 ADEN 비트가 0이면 전력을 소모하지 않음

##변환 시작
ADCSRA의 ADSC비트에 1을 쓰면 변환을 시작한다.
변환 중에는 ADSC를 1로 유지하다가 완료되면 하드에어가 자동으로 0으로 바꾼다.
변환 도중 채널을 바꾸면, 현재 변환을 마친뒤 채널이 바뀐다.
프리러닝 모드 : ADCSRA의 ADFR비트를 1로 설정한다. 첫 변환 이후 ADIF(인터럽트 플레그)클리어 여부와 상관없이 계속 자동으로 변환한다.

##프리스케일러와 변환 타이밍
해상도가 낮으면 샘플링 속도를 올릴 수 있다.
ADCSRA의 ADPS비트로 프리스케일 비율을 설정할 수 있다.

변환시간 
일반 변환 : 13 ADC 클럭 사이클

##ADC 기준접압
  VREF는 ADC의 변환 범위를 나타낸다. 단일 종단 채널의 입력이 VREF를 초과하면 결과값이 Ox3FF 근처로 나온다.
  AVCC는 수동 스위치를 통해 ADC에 연결됨. 내부 2.56V는 내부 밴드갭 기준전압(VBG)을 증폭기로 만들어냄.
  AREF핀은 ADC에 직접 연결되어 있어서, AREF-GND 사이에 케패시터를 달면 노이즈 내성이 좋아진다.
  AVCC->2.56V로 전환이 가능하지만 첫 변환 결과는 부정확할 수 있어서 버리는 것을 권장함

##아날로그 노이즈 저감 기법
  아날로그 신호 경로는 최대한 짧게, 그라운드 플레인 위로 배선하고 고속 디지털 대선과 멀리 떨어뜨려야한다. -> 가변저항 위치를 atmega랑 가까운데 배치한다.
  AVCC 핀은 LC필터망을 통해 디지털 VCC 전원에 연결할 수 있다(LC 필터를 통해 노이즈를 줄일 수 있다.)
  ADC 포트 핀을 디지털 출력으로 쓰는 경우, 변환 중에는 스위칭하지 않도록 해야한다.
